# What you need

*This chapter is an outline, still to be written. It will cover:*

- Printer: build volume needed for each part, and how to check it with `printer_size`.
- Filament: PETG (tested), why not PLA for a base that may sit in a warm room or a car, and how much to allow.
- Software: OpenSCAD 2021.01 or later, installing BOSL2, and a slicer.
- Hardware list with quantities and sources: hinges, mending plates, screws, nuts, rods, cushions.
- Tools: calipers, drill bits for the membranes, pliers for the knock-out walls.
