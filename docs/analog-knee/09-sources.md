# Sources

1. Interlink Electronics, *FSR 400 Series Integration Guide* and *FSR X &
   UX Series Integration Guide*: resistance against force, drive voltage,
   current limit, repeatability and drift.
2. [MOC3023M random-phase triac driver optocoupler](https://www.onsemi.com/pdf/datasheet/moc3023m-d.pdf),
   onsemi data sheet.
3. H11AA1 AC-input optocoupler, Vishay data sheet: current-transfer ratio
   (20% minimum at 10 mA) and isolation.
4. LM334 three-terminal adjustable current source, Texas Instruments data
   sheet: set current, temperature coefficient, headroom.
5. MCP6561/2/4 push-pull output comparators, Microchip data sheet.
   G5LE relay, Omron (now Aratas) data sheet: coil current.
6. [BTA16, BTB16 and T16 series 16 A triacs](https://www.st.com/en/thyristors-scr-and-ac-switches/bta16.html),
   STMicroelectronics data sheet.
7. Siemens (later Infineon), TCA785 phase control IC data sheet: the
   synchronized ramp and comparator this design follows.
8. *A Force-Sensing Pedal*, in this repository (`docs/fsr-pedal/`).
9. *Inside a Switching Circuit*, in this repository (`docs/switching/`).
10. *Speed Control of Universal Motors in Sewing Machines*, in this
    repository (`docs/motor-control/`), §9 and §11; and the MCU
    controller's schematic and README in `hardware/mcu-controller/`.
11. The User's Guide's knee-controller chapter, for the knee's mechanism
    and feel.

The simulation and the figures are generated by
`tools/make_analog_knee_figures.py` in the project repository. The
schematic is drawn by the same script; there is no KiCad source yet.
