VSM Base

A 3D-printable base for vintage sewing machines, and the papers on motor speed control written alongside it.

Snapshot of Development Build v86, taken November 22, 2026.

These may not be the latest versions. They are copied here by hand from time to time, not built automatically, so the sources in the repository may have moved on since. Each release on its Releases page carries the documents built from that release; make html or make pdf in a copy of the repository builds them from the current source.

Each document is a single self-contained page, its pictures and diagrams included. To read one offline, save the page from your browser (as a complete web page, or HTML only; either works) and open the saved file.

Safety status of the motor controls: research only. None of the motor-control designs in these documents, including the base's knee controller option and the papers' circuits, is safe to build as drawn. They are research artifacts, published as the work progresses: studies of how existing and historical controls work, what their hazards are, and what a safer replacement would need. None has been built, tested, measured, or assessed against an electrical safety standard. Do not build a controller from these documents or connect one to the mains.
